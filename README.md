# ATM Machine Controller Using Verilog HDL

## Project Overview
Designed and implemented an ATM Machine Controller using Verilog HDL based on a Finite State Machine (FSM) approach. The project simulates the basic operations of an ATM system, including card insertion, PIN verification, transaction selection, balance inquiry, cash withdrawal, and insufficient balance detection.

The controller manages different ATM operations through predefined states and controls the transition between states based on user inputs and transaction conditions.

## Features
- Card insertion detection.
- PIN verification.
- Limited PIN attempts and card locking mechanism.
- Transaction selection.
- Balance inquiry.
- Cash withdrawal.
- Insufficient balance detection.
- Balance update after successful withdrawal.
- Error handling and transaction completion.

## Design Approach
- Implemented using Verilog HDL.
- FSM-based control logic.
- Sequential and combinational logic.
- Clock and reset-based state management.
- Testbench-based functional verification.

## Tools Used
- Verilog HDL
- QuestaSim

## Objective
To understand and implement real-world digital system control using FSM concepts, sequential logic, and Verilog HDL while developing practical RTL design and verification skills.
